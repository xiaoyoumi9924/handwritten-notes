# 第三款个人字体（第六轮）

本地测试配置：`configs/personal_v6_test.json`。已接入 Web 界面的“游丝细行体”选项。

默认使用 `trajectories.zip`（实写优先版）；另保留 `model_trajectories.zip`。两份轨迹原样保留，来源及原始校验记录见 `manifest.json` 与 `ASSET_LICENSES.md`。汉字为 6763 字轨迹，包含实写描线、模型生成及手工设计字形；英文、数字与公式采用 Caveat 配套字体，数字 1、中文标点按本配置适配，并非用户训练字形。

测试文稿：`examples/personal_v6_建设地方.md` 和 `examples/personal_v6_数字公式表格.md`。配置中的路径相对于项目根目录解析。网页会在本机保存选中的书体和参数。
