# 自动裁边和 DocRes 加速验证

## 已接入：浅色纸张与暖色桌面分离

在原有四边形、局部纸边检测均未成功时，增加保守的颜色分离回退：仅对完整的浅色纸张四边形生效，并要求四条边的内外颜色、亮度变化均有足够证据，角点不能贴近画面边缘。证据不足继续保留原图，用户可手动校正。滤镜预览版本为 15，旧预览不复用。

原有公开记事本照片之前未识别纸张，扫描结果保留大面积木桌；本次识别到四角，校正后的对照是 `output/docres-independent/cropping-before-after.jpg`。同批图表、公式、收据和中文笔记也有检测结果，但只有少量真实样本，不能声称检测准确率或覆盖所有桌面、纸色与拍摄角度。任何自动选区仍可能选错，尤其是纸面与背景颜色接近、纸张弯曲、四边遮挡或贴边时；应检查页面校正。

## 本机模型加速实验

修改 `scripts/evaluate_docres.py`，允许使用 `DOCRES_DEVICE=mps` 在本机 Apple 图形处理器推理。仍需手工指定，默认 CPU；本项目的产品滤镜尚未接入 DocRes 或该加速，不会因为这次试验在后台额外运行模型。

以长边768，CPU 4 线程，测量模型推理及张量输出复制、不含模型加载、预处理、上传、导出：

| 图 | 任务 | CPU | MPS |
| --- | --- | ---: | ---: |
| 课程表 | appearance | 4.91 秒 | 2.77 秒（该组首次） |
| 课程表 | deshadowing | 4.83 秒 | 1.56 秒 |
| 中文笔记 | appearance | 6.57 秒 | 1.49 秒 |
| 中文笔记 | deshadowing | 5.04 秒 | 1.62 秒 |

CPU 与 MPS 对应 PNG 的平均通道差 0.0003–0.0015、最大差1（0–255 量纲）；不代表文字语义准确率。只有两张图片，且没有评估批量、内存、其他电脑或完整端到端体验。时间仅用于本机初步参考。结果位于 `output/docres-mps/`。

新增合成暖色背景上完整纸张的角点误差检查，以及纯背景、纸张贴边负样本；扫描相关 52 项和 14 个子测试、前端扫描状态测试通过。真实 HTTP 测试重新上传记事本，确认自动选区和去阴影扫描成功，返回版本15。原有图片如需更新须刷新页面并重新扫描；复杂选区需检查。
