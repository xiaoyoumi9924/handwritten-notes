# DocRes 光照图和原图融合试验

目标是用低分辨率 DocRes 输出估算缓慢变化的亮度增益，将增益作用到较高分辨率原图，减少直接放大模型输出时的文字细节损失。实验与当前产品滤镜分开，尚未接入。

## 方法与素材

使用上一轮四张图片的 768 长边 DocRes appearance 输出，以及同一原图长边限制为 1600 的版本。对输入与输出各自估计纸面背景，以亮度比值求增益，限制在 1–2.2 倍，再平滑并缩放至大图；RGB 三通道共用增益。它保留了采样前的大图结构，但仍可能发生颜色通道截断，也无法恢复源照片原本的失焦信息。四张是中文笔记、公式页、彩色课程表和收据，不是充分的独立测试集；没有像素标注真值。所有对比未进行纸面校正。

运行：

```sh
PYTHONPATH=src .venv/bin/python scripts/evaluate_docres.py
PYTHONPATH=src .venv/bin/python scripts/evaluate_docres_illumination.py
PYTHONPATH=src .venv/bin/python scripts/evaluate_docres_color_blend.py
```

第一步需要本机已放置的模型源码与权重，设置方法见 `docres-local-evaluation.md`。对比图和指标保存在 `output/docres-illumination-study/`。`*-comparison.jpg` 依次是原图、当前去阴影、低分辨率模型输出和光照图增强；`*-hybrid-comparison.jpg` 是原图、当前去阴影、颜色混合试验。

## 观察与结论

- 课程表经光照图处理后保留了彩色填充和原图细节，但纸面偏暖、阴影仍残留；笔记和公式页相对于当前滤镜仍偏灰，不符合预期的干净白底。
- 光照图计算本机每张约 0.09–0.16 秒，**不包含**生成模型输出约 4.8–6.6 秒及模型加载；不是端到端计时。
- 尝试仅将模型识别的彩色区域与当前去阴影混合：课程表填色出现零碎边界；收据上平均蒙版值为 35.64%，显示规则对该图的偏色响应很大。平均蒙版值不是误识别率，也不是准确率。小样本无标注，不能判断收据哪些区域为真实色彩。
- 因结果存在残影、色块边界及泛化不确定，以上方案均没有替换应用算法。需要改进颜色区域检测、在纸面与图片区域分开验证，并以高分辨率混排真值检查文字与图线；复杂折痕和大块阴影仍是限制。
